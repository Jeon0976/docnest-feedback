这里接收 [Docnest](https://docnest.net) 的问题反馈和功能建议。Docnest 是一款 Mac 应用，会把你的 AI 智能体写的文档汇集到屏幕边缘的文档架上。这里没有源代码。表单是英文的，但你可以用中文填写。

## [报告问题 →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

登录 GitHub 后，大约 30 秒就能完成。

1. 登录 GitHub，免费账号即可。
2. 写下发生了什么。只有这一栏必填。
3. 有截图的话拖进来，然后提交。

在 Docnest 中选择 **帮助 → 报告错误…**，就会打开这个表单，Docnest 版本、macOS 版本和 Mac 型号都已自动填好。

> **Issue 所有人都能看到——请不要粘贴文档内容、许可证代码或机密信息。**

## 建议功能

[提交功能建议](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml)，告诉我们你想做什么、卡在了哪里。如果已经有人提过，在那个 issue 下点个 👍 也很有帮助。
