這裡接收 [Docnest](https://docnest.net) 的問題報告和功能建議。Docnest 是一款 Mac App，會把你的 AI 代理寫的文件集中到螢幕邊緣的文件架。這裡沒有原始碼。表格是英文的，但你可以用中文填寫。

## [報告問題 →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

登入 GitHub 後，大約 30 秒就完成。

1. 登入 GitHub，免費帳戶即可。
2. 寫下發生了甚麼事。只有這一欄必須填寫。
3. 有截圖的話拖進來，然後提交。

在 Docnest 選擇 **輔助說明 → 報告錯誤⋯**，就會開啟這個表格，Docnest 版本、macOS 版本和 Mac 型號都已預先填好。

> **Issue 所有人都看得到——請不要貼上文件內容、授權碼或機密資料。**
