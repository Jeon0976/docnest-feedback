Signalements de bugs et suggestions pour [Docnest](https://docnest.net), l’app Mac qui rassemble ce qu’écrivent vos agents d’IA dans un volet au bord de l’écran. Il n’y a pas de code source ici. Le formulaire est en anglais, mais vous pouvez écrire en français.

## [Signaler un bug →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

Une fois connecté à GitHub, il faut environ 30 secondes.

1. Connectez-vous à GitHub. Un compte gratuit suffit.
2. Décrivez ce qui s’est passé. C’est le seul champ obligatoire.
3. Ajoutez une capture d’écran si vous en avez une, puis envoyez.

Dans Docnest, **Aide → Signaler un bug…** ouvre ce formulaire, avec la version de Docnest, la version de macOS et le modèle de Mac déjà remplis.

> **Les issues sont publiques : ne collez ni contenu de document, ni clé de licence, ni secret.**

## Proposer une fonction

[Ouvrez une suggestion](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml) et dites-nous ce que vous essayiez de faire et ce qui vous a bloqué. Si quelqu’un l’a déjà demandé, un pouce levé sur son issue compte aussi.
