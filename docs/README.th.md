ที่นี่รับรายงานบั๊กและคำแนะนำฟีเจอร์ของ [Docnest](https://docnest.net) แอป Mac ที่รวบรวมสิ่งที่เอเจนต์ AI ของคุณเขียนไว้ในแถบข้างที่ขอบจอ ที่นี่ไม่มีซอร์สโค้ด แบบฟอร์มเป็นภาษาอังกฤษ แต่เขียนเป็นภาษาไทยได้

## [รายงานบั๊ก →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

ถ้าลงชื่อเข้าใช้ GitHub อยู่แล้ว ใช้เวลาประมาณ 30 วินาที

1. ลงชื่อเข้าใช้ GitHub บัญชีฟรีก็ได้
2. เล่าว่าเกิดอะไรขึ้น ช่องนี้เป็นช่องเดียวที่ต้องกรอก
3. ถ้ามีภาพหน้าจอ ลากมาวาง แล้วกดส่ง

ใน Docnest เลือก **วิธีใช้ → รายงานข้อบกพร่อง…** เพื่อเปิดแบบฟอร์มนี้ โดยกรอกเวอร์ชัน Docnest เวอร์ชัน macOS และรุ่นของ Mac ไว้ให้แล้ว

> **ทุกคนเห็น issue ได้ อย่าวางเนื้อหาเอกสาร คีย์ไลเซนส์ หรือข้อมูลลับ**

## เสนอฟีเจอร์

[เปิดคำขอฟีเจอร์](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml) แล้วเล่าว่าคุณพยายามทำอะไรและติดตรงไหน ถ้ามีคนขอไว้แล้ว กด 👍 ที่ issue นั้นก็ช่วยได้

## อีเมล

เรื่องการซื้อ ไลเซนส์ หรือบั๊กที่บอกต่อสาธารณะไม่ได้: **hello@sanmarustudio.com**

## ความปลอดภัย

อย่าแจ้งปัญหาความปลอดภัยหรือความเป็นส่วนตัวเป็น issue สาธารณะ [แจ้งแบบส่วนตัว](https://github.com/Jeon0976/docnest-feedback/security/advisories/new) หรืออ่าน[นโยบายความปลอดภัย](../SECURITY.md) (ภาษาอังกฤษ)
