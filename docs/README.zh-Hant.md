這裡接收 [Docnest](https://docnest.net) 的問題回報和功能建議。Docnest 是一款 Mac App，會把你的 AI 代理寫的文件集中到螢幕邊緣的文件架上。這裡沒有原始碼。表單是英文的，但你可以用中文填寫。

## [回報問題 →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

登入 GitHub 後，大約 30 秒就能完成。

1. 登入 GitHub，免費帳號即可。
2. 寫下發生了什麼事。只有這一欄必填。
3. 有截圖的話拖進來，然後送出。

在 Docnest 中選擇 **輔助說明 → 回報錯誤⋯**，就會開啟這個表單，Docnest 版本、macOS 版本和 Mac 機型都已自動填好。

> **Issue 所有人都看得到——請不要貼上文件內容、授權碼或機密資訊。**

## 建議功能

[提出功能建議](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml)，告訴我們你想做什麼、卡在哪裡。如果已經有人提過，在那個 issue 按個 👍 也很有幫助。
