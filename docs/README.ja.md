[Docnest](https://docnest.net)は、AIエージェントが書いた文書を集めて画面の端のシェルフに並べるMacアプリです。このリポジトリではバグ報告と機能の提案を受け付けています。ソースコードはありません。フォームは英語ですが、日本語で書いていただいて大丈夫です。

## [バグを報告する →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

GitHubにサインインしていれば、30秒ほどで終わります。

1. GitHubにサインインします。無料アカウントで大丈夫です。
2. 何が起きたかを書きます。必ず埋める欄はここだけです。
3. スクリーンショットがあればドラッグして、送信します。

Docnestで **ヘルプ → バグを報告…** を選ぶと、このフォームが開きます。Docnestのバージョン、macOSのバージョン、Macのモデルは入力済みです。

> **Issueは誰でも見られます。文書の内容、ライセンスコード、秘密の値は貼り付けないでください。**

## 機能の提案

[機能提案フォーム](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml)に、何をしようとしてどこで困ったかを書いてください。同じ提案がすでにあれば、そのIssueにリアクションを付けるだけでも十分です。
