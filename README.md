# Docnest feedback

Bug reports and feature requests for [Docnest](https://docnest.net), the Mac app that collects what your AI agents write and puts it on a shelf at the edge of your screen. There's no source code here.

[한국어 안내](#한국어)

## [Report a bug →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

Once you're signed in, it takes about 30 seconds.

1. Sign in to GitHub. A free account is fine.
2. Tell us what happened. It's the only box you have to fill in.
3. Drop in a screenshot if you have one, then submit.

From the next app update, **Help → Report a Bug…** in Docnest opens this form with your Docnest version, macOS version and Mac model already filled in.

> **Issues are public — don't paste document contents, license keys or secrets.**

## Suggest a feature

[Open a feature request](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml) and tell us what you were trying to do and what got in the way. If someone has already asked for it, a thumbs-up reaction on their issue counts too.

## Email

For purchases, licenses or a bug you can't describe in public: **hello@sanmarustudio.com**

## Security

Please don't file security or privacy problems as public issues. [Report them privately](https://github.com/Jeon0976/docnest-feedback/security/advisories/new) or read the [security policy](SECURITY.md).

## 한국어

[Docnest](https://docnest.net)는 AI 에이전트가 쓴 문서를 모아 화면 가장자리 선반에 올려 두는 Mac 앱입니다. 이 저장소에서는 버그 제보와 기능 제안을 받습니다. 소스 코드는 없습니다.

### [버그 제보하기 →](https://github.com/Jeon0976/docnest-feedback/issues/new?template=bug_report.yml)

GitHub에 로그인한 상태라면 30초 정도 걸립니다.

1. GitHub에 로그인합니다. 무료 계정이면 됩니다.
2. 무슨 일이 있었는지 적습니다. 꼭 채워야 하는 칸은 이것 하나입니다.
3. 스크린샷이 있으면 끌어다 놓고 제출합니다.

다음 앱 업데이트부터는 Docnest 안에서 **도움말 → 버그 제보…** 메뉴를 누르면 같은 양식이 열립니다. Docnest 버전, macOS 버전, Mac 모델은 미리 채워져 있습니다.

> **이슈는 누구나 볼 수 있습니다. 문서 내용, 이용권 코드, 비밀 값은 붙여 넣지 마세요.**

### 기능 제안

[기능 제안 양식](https://github.com/Jeon0976/docnest-feedback/issues/new?template=feature_request.yml)에 무엇을 하려다 어디서 막혔는지 적어 주세요. 이미 같은 제안이 있다면 그 이슈에 공감 반응을 남겨 주셔도 됩니다.

### 이메일
